# VitalPet Doctor Handoff

## Stack
- **PDF generation**: `pdf` 3.x (pure Dart layout engine)
- **Sharing**: `printing` 5.x (native share sheet integration from Dart)
- **No native bridge required** — this is entirely Dart code

## Generation flow
```dart
// lib/features/handoff/handoff_generator.dart

Future<void> generateAndShare({
  required DateRange dateRange,
  required WidgetRef ref,
}) async {
  // 1. Read check-ins from DB
  final checkins = await ref.read(checkInDaoProvider)
      .findByDateRange(dateRange.start, dateRange.end);

  // 2. Optional: re-query health data
  final healthData = await ref.read(healthAdapterProvider).fetchSummary(dateRange);

  // 3. SLM narrative (de-identified)
  final narrative = await ref.read(narrativeGeneratorProvider)
      .generate(NarrativeContext.from(checkins, healthData));

  // 4. Build chart data (pure Dart)
  final trendData = ChartDataBuilder.buildTrendChart(checkins);
  final heatmapData = ChartDataBuilder.buildHeatmap(checkins);

  // 5. Build PDF document in memory
  final pdf = pw.Document();
  pdf.addPage(_buildPage1(checkins, trendData, narrative));
  pdf.addPage(_buildPage2(checkins, heatmapData));
  if (healthData != null) pdf.addPage(_buildPage3(healthData, trendData));

  // 6. Write audit entry BEFORE sharing
  await ref.read(auditLogDaoProvider).append(
    AuditEvent.handoffExport(dayRange: dateRange.toString()),
  );

  // 7. Share via native share sheet (printing package)
  await Printing.sharePdf(
    bytes: await pdf.save(),
    filename: 'vitalpet_summary_${DateFormat('yyyyMMdd').format(DateTime.now())}.pdf',
  );
  // printing package writes to a temp file, opens share sheet, deletes after — zero persistence
}
```

## PDF structure

### Page 1 — Summary
```dart
pw.Page _buildPage1(List<CheckIn> checkins, TrendData trend, HandoffNarrative narrative) {
  return pw.Page(
    build: (pw.Context ctx) => pw.Column(children: [
      // Clinical narrative (SLM-generated, filtered)
      _buildNarrativeBlock(narrative), // headline bolded, context paragraph, questions
      _buildSummaryStats(checkins),    // date range, completion rate, avg wellness, top domains
      _buildTrendChart(trend),         // line chart via pw.Chart — missed days as grey gaps
    ]),
  );
}
```

### Page 2 — Symptom Chronicle
```dart
pw.Page _buildPage2(List<CheckIn> checkins, HeatmapData heatmap) {
  return pw.Page(
    build: (ctx) => pw.Column(children: [
      _buildCalendarHeatmap(heatmap),  // GitHub-style — colour intensity = wellness score
      _buildChronicleList(checkins),   // notable events: score ≤ 4, deviation alerts, >2 domains
    ]),
  );
}
```

### Page 3 — Health Correlation (optional)
Only rendered when `healthData != null` (HealthKit/Health Connect connected):
- Dual-axis chart: wellness vs sleep duration
- Dual-axis chart: wellness vs step count

## Non-removable disclaimer
Every page footer must include:
```dart
pw.Footer(build: (ctx) => pw.Text(
  'This summary was generated by VitalPet and is not a medical record. '
  'Please discuss with your clinician.',
  style: const pw.TextStyle(fontSize: 8),
))
```
This is in a shared `_pageTheme()` function applied to every `pw.Page` — it cannot be conditionally removed.

## Narrative generator — de-identification
The `NarrativeContext` passed to the SLM must contain only aggregated statistics:
```dart
class NarrativeContext {
  final DateRange dateRange;     // date strings only — no patient name
  final int totalCheckins;
  final double avgWellness;
  final List<String> topDomains;
  final String trendDirection;   // 'improving' | 'stable' | 'declining'
  final List<DeviationSummary> deviations;
  final double? sleepAvgHours;
  final double? sleepBaselineHours;
  // No: user name, device ID, exact location, account ID
}
```
